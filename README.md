# Web Application Security Assessment

## Project Overview

This project documents a web application security assessment of OWASP Juice Shop, an intentionally vulnerable application used for cybersecurity learning and authorized testing.

The assessment is conducted in a local lab environment to practise web application testing, HTTP request analysis, evidence collection, and security reporting.

## Objectives

* Understand normal web application behaviour.
* Inspect HTTP requests and responses.
* Test search input handling.
* Review session behaviour and authorization controls.
* Document observations and potential security weaknesses.
* Recommend practical security improvements.

## Tools Used

* OWASP Juice Shop
* Burp Suite Community Edition
* Web browser and developer tools
* Git and GitHub
* Markdown for documentation

## Scope

Testing focuses on authentication, authorization, input handling, session behaviour, and selected API endpoints within the authorized local lab.

## Project Structure

* `architecture.md` — Lab architecture and setup.
* `test-plan.md` — Assessment scope and testing approach.
* `search-test-notes.md` — Search testing notes.
* `report.md` — Assessment report.
* `evidence/` — Screenshots, requests, responses, and testing records.
* `findings/` — Documented security findings.

## Methodology

Testing follows a structured approach: establish a baseline, perform controlled tests, capture evidence, assess the results, and document remediation recommendations.

## Status

Initial documentation and evidence have been committed to GitHub. The assessment is completed.

## Responsible Testing

All testing is limited to the intentionally vulnerable local lab. No unauthorized systems are targeted.

## Disclaimer

This project is for educational purposes and demonstrates practical web application security assessment skills.
